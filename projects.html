Rendering with my WebGPU graphics library

Monte Carlo Path Tracer

I developed a physically based renderer using Monte Carlo path tracing to simulate realistic global illumination. This renderer is capable of rendering features such as soft shadows, color bleeding, caustics, fresnel refractions, and image-based lighting for high-fidelity images. To reduce noise in the outputs, I also implemented importance sampling and low discrepancy quasi-random sampling.

Skills: C++, Eigen, Physically Based Rendering, Ray Tracing, Computer Graphics

Stable NeRF

Stable NeRF in an integration of Neural Radiance Fields (NeRF) with Stable Diffusion to enable geometrically consistent one-shot novel view generation. It uses an Instant NGP/Tiny-CUDA-NN based latent space neural feature field to generate novel view feature maps in the latent space. A Stable Diffusion network, fined tuned with IP Adapters, is conditioned on these feature maps and the camera parameters as plucker coordinates,

Skills: Python, PyTorch, Fine-tuning, Neural Rendering, Generative AI, 3D Vision

Turbo-GS

As a part of Brown IVL (Interactive 3D Vision & Learning Lab), I contributed to the development of Turbo-GS, a research paper, recently published, focused on optimizing 3D Gaussian Splatting for real-time training. My contributions included implementing CUDA-based acceleration techniques and optimizing GPU workloads to enhance performance.

Skills: PyTorch, C++, Cuda, GPU Optimization, Neural Rendering, Deep Learning

GFX-MAIN

Gfx-Main is a high-level graphics library that I am developing for the web. It is written in TypeScript and uses WebGPU for real-time rendering. It currently supports basic 3D rendering, lighting, materials, textures, and .obj file loading. It is still in development, and I am planning to add more features like integrating real-time ray-tracing, similar to the one in the home page of this website.

Skills: TypeScript, JavaScript, WebGPU, WGSL, Real-Time Rendering, 3D Graphics
